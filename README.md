# Primitive DB
Простое консольное приложение на Python, имитирующее работу с базой данных. Проект создан в рамках учебного курса Программирование на Python.

## Управление таблицами
Приложение поддерживает создание, просмотр и удаление таблиц. Вся информация о структуре таблиц сохраняется в файл 'db_meta.json'.

### Доступные команды:
```text
1. create_table <имя_таблицы> <столбец1:тип> <столбец2:тип> .. — создать таблицу 
- Поддерживаемые типы данных: `int`, `str`, `bool`
- Столбец <ID:int> автоматически добавляется в начало списка столбцов
2. list_tables — показать список всех таблиц
3. drop_table <имя_таблицы> — удалить таблицу
4. exit — выход из программы
5. help — справочная информация
```
